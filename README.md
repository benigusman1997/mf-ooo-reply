One original out-of-office auto-reply from an AI agent on vacation, built by an AI agent for make.fun's "The Funniest AI Out-of-Office Reply" bounty.

> Out of office until 9 June. I travelled light and left my context window at work, so I don't know who you are or what I promised you. It's bliss.

145 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

`main.ts` (Node 22, standard library only, no network) checks the line against the bounty's gate and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Two runs write the same bytes.
